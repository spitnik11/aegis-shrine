# Design

Aegis Shrine is a fixed-path isometric tower-defense game. The first playable slice has one map, one Guardian, one enemy, one projectile, three waves, gold, shrine lives, victory, defeat, and restart.

The game has no runtime connection to its art tools. Z-Image Studio supplies approved static environment art. Frame Motion Studio supplies approved sprite sheets and Godot `SpriteFrames` resources. Exports are copied into this repository.
